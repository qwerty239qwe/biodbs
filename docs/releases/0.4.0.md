# biodbs 0.4.0

Released: 2026-07-05

`0.4.0` expands database coverage to match the reference databases supported by
the QIIME 2 plugin [RESCRIPt](https://github.com/bokulich-lab/RESCRIPt), and
hardens live-API reliability.

## New database fetchers

- **PR2** — Protist Ribosomal Reference release files via the GitHub Releases API.
- **GreenGenes** — release-directory browsing and downloads over `ftp.microbio.me`.
- **EUKARYOME** — eukaryote-wide rRNA (SSU/LSU/ITS/longread) reference archives.
- **MIDORI2** — QIIME-formatted mitochondrial reference files (fasta + taxon sidecar).
- **UNITE** — fungal/eukaryote ITS release archives resolved via the PlutoF DOI API.
- **GTDB** and **HOMD** fetchers.

Each fetcher ships offline (mocked) unit tests and live integration tests, plus
API reference docs and a user guide.

## Reliability

- Routed PubChem requests through the shared rate-limited `request_with_retry`
  helper, so the configured per-host rate limit and 429 backoff take effect.
- Live integration CI now reruns only failed tests (`pytest-rerunfailures`) to
  absorb third-party API throttling of CI IP ranges, and covers the new
  databases' live suites.

## Not yet included

BOLD is deferred: its legacy API endpoint is retired and the current Portal API
requires a multi-step token flow with no RESCRIPt precedent. See
`docs/dev/rescript-parity-plan.md`.

## Upgrade

```bash
pip install --upgrade biodbs==0.4.0
```

No API migration is required for users upgrading from `0.3.1`.
