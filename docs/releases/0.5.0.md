# biodbs 0.5.0

Released: 2026-07-23

`0.5.0` adds a taxonomic ID **canonical / mapping table**: resolve organism names
and per-database lineage strings to one hub identifier (NCBI Taxonomy `taxid`) and
join any two reference databases on it.

## Taxonomy Mapping

- New [`biodbs.taxonomy`](../taxonomy/mapping.md) API: `TaxonomyMapper`
  (`map_names`, `map_lineage`, `resolve`), `load_taxdump` (parse
  `new_taxdump.tar.gz` into an in-memory hub table), and `merge_on_hub`
  (cross-database join). Output is a pandas DataFrame keyed on `hub_taxid`.
- Added `biodbs.translate.translate_taxon_names` (also available at the top level)
  to resolve names through a configured `TaxonomyMapper`, returning its standard
  mapping DataFrame. Existing taxonomy imports remain supported.
- Added the **GBIF** backbone fetcher (`gbif_match_name`/`gbif_match_names`) as
  the all-life canonical-name and synonym authority.
- Added `ncbi_taxonomy_name_to_id` (name → taxid via E-utilities esearch).
- Added `gtdb_ncbi_crosswalk` (GTDB species → NCBI taxid, majority vote from
  GTDB metadata) so GTDB lineage strings join the hub directly.

## Unified Translation API

- `translate_chemical_ids` covers existing PubChem conversions, ChEMBL/PubChem
  structure-based mappings, and KEGG compound/drug mappings. PubChem SIDs remain
  distinct from CIDs. `translate_gene_ids` accepts the KEGG backend.
- Optional `GeneMapper`, `ChemicalMapper`, and `ProteinMapper` objects reuse
  configuration; existing calls do not require them and retain their effective
  defaults. Explicit conflicting settings raise rather than being ignored.
- Protein convenience functions share `translate_protein_ids`, which adds
  `all_matches=True` for list-valued dictionaries and a gene-name review filter.
- Existing helpers/imports remain supported without deprecation warnings, keeping
  their positional arguments, output columns, dictionary defaults, and scalar/list
  behavior. Main KEGG routes require explicit `bulk=True` for empty-input
  whole-database conversion; legacy KEGG helpers retain their existing behavior.
- Taxonomic name translation can use online NCBI by default, or a configured
  offline/enrichment mapper. No taxdump is downloaded automatically.

See the [translation guide](../translate/index.md#optional-reusable-mappers).

## Offline Chemical Reference

- Added `build_chemical_mapping_db(path, source="unichem")`, available from
  `biodbs.translate` and the top level, to build the full published UniChem
  ChEMBL/PubChem CID crosswalk in SQLite.
- Distinct pairs preserve one-to-many matches and have indexes in both query
  directions. Provenance records the URL, retrieval timestamp, archive SHA-256,
  and mapping count. The archive hash identifies the snapshot, not independent
  upstream checksum verification.
- Downloads are temporary; imports are bounded-memory and transactional. Failed
  imports roll back the mapping schema and data. Existing mapping tables fail
  rather than being replaced, and unrelated tables remain unchanged.
- Existing online translators retain their behavior and do not automatically
  use this SQLite file. Only the UniChem source 1 to source 22 export is supported.

See [Build Mapping Databases](../getting-started/mapping-databases.md).

## Reliability Fixes

- MIDORI2 resolves explicit releases from the current and legacy Zenodo archives
  after the upstream host migration. Downloads verify the bundle MD5 and extract
  only the requested gzip file atomically, removing temporary files. Legacy
  version spellings and explicit direct-file mirrors remain supported; default
  `build_url` now returns a ZIP URL and requires a metadata lookup. See the
  [MIDORI2 guide](../fetch/midori2.md) for temporary disk-space requirements.
- `merge_on_hub` never matches missing taxids. Left, right, and outer joins keep
  unresolved rows separately; inner joins include only matching non-missing IDs.
- Offline taxonomy matching distinguishes accepted scientific names from
  synonyms, ignoring case and surrounding whitespace. GBIF accepted/synonym
  results take precedence when supplied.
- GTDB, HOMD, and GreenGenes downloads stream to temporary files and replace the
  destination only after success. Interrupted transfers cannot be reused as
  completed files, and failed overwrites preserve the existing file.
- HTTP retries now handle real error responses correctly. Batch calls start at
  evenly spaced intervals using a monotonic clock; non-positive rates raise
  `ValueError`.
- Added 74 regression cases covering these fixes and live-test isolation.

## CI Reliability

Added `gbif`, `disease-ontology`, and `uniprot` to the CI integration matrix and
expanded the existing `ncbi` job to cover its full live-test group. Live Disease
Ontology, NCBI, and UniProt tests use the `integration` marker, so the unit-test
command `pytest -m "not integration"` runs their offline tests only.

SILVA checks discover a published classifier instead of assuming a fixed release
folder. QuickGO's whole-organism GO ORA checks run in a separate 25-minute job;
other integration jobs retain their 12-minute limit. Missing GO annotation names
fall back to the GO ID so pathway caching succeeds and repeated calls reuse it.

## Translator Accuracy and Performance

- Ensembl symbol inputs now return the requested namespace, rather than a gene
  ID under a transcript/protein/external-ID column. Stable-ID identity conversions
  need no network request, and repeated inputs reuse a lookup within the call.
- UniProt mapping and explicit-ID NCBI gene fetches read all result pages.
- HGNC multi-target translation fetches each unique input once. A 2,000-row batch
  containing two unique inputs and two targets now needs two lookups, not 4,000,
  while preserving every output row.
- Multi-target rows retain duplicate inputs and missing values. Chemical
  dictionaries preserve original keys and `None`; BioMart omits missing mappings.
- RefSeq protein/mRNA types remain distinct. HGNC protein aliases raise
  `ValueError`; current NCBI reports may lack RefSeq output accessions. RefSeq
  input lookups are associated by separate queries rather than guessed batch keys.
- ChEMBL–PubChem conversions verify structure identity. KEGG `pubchem:` values
  are documented as Substance IDs (SIDs), not Compound IDs (CIDs).

See [translator validation](../translate/genes.md#accuracy-and-performance-checks)
for tests, measured request counts, live latency, and one-to-many limitations.

## Upgrade

```bash
pip install --upgrade biodbs==0.5.0
```

Public entry points are unchanged for users upgrading from `0.4.1`;
the corrected HGNC protein-namespace behavior requires the adjustment below.

If you previously requested `refseq_protein` from HGNC, switch to UniProt;
HGNC's `refseq_accession` field supplies RNA accessions, not protein IDs.
